# help_texts.py — справка и контакты

По требованиям к проектам нужны **инструкция по пользованию** и
**актуальные контакты разработчиков**. Оба текста здесь:

| Имя                | Где показывается                     |
|--------------------|--------------------------------------|
| `INSTRUCTION_HTML` | Справка → Инструкция (F1)            |
| `about_html()`     | Справка → О программе                |
| `DEVELOPERS`       | список (имя, e-mail) для «О программе» |

> ⚠️ **Перед сдачей впишите свои данные в `DEVELOPERS`** —
> сейчас там заглушка.

Тексты — обычный HTML (Qt понимает `<h2>`, `<ul>`, `<b>` и т.д.).
