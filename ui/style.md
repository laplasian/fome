# style.py — внешний вид и нормировка

## Оформление

- `LINE_WIDTH = 2.8` — толстые линии расчёта (требование условия).
- `EXPERIMENT_LINE_WIDTH = 1.6` — эксперимент тоньше и чёрный, чтобы расчёт был виден поверх.
- `COLORS` — у каждой величины свой цвет, одинаковый во всех окнах.
- `apply_matplotlib_style()` — крупные шрифты и сетка, вызывается один раз в `main.py`.

## Нормировка

Нужна, чтобы сравнивать **форму** кривых с разным масштабом.
Применяется **только к отображению** — в файл всегда пишутся исходные значения.

| Режим    | Формула                                                    |
|----------|------------------------------------------------------------|
| `none`   | $y$                                                        |
| `max`    | $\dfrac{y}{\max\lvert y\rvert}$ — максимум по модулю равен 1 |
| `minmax` | $\dfrac{y - y_{min}}{y_{max} - y_{min}}$ — кривая в $[0, 1]$ |

**Автомасштаб** (в `plot_grid.py`): если включён — оси подстраиваются под данные
при каждом пересчёте; если выключен — сохраняются пределы, выставленные лупой.
