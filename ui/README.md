# ui/ — интерфейс программы

PySide6 (окна, кнопки) + matplotlib (графики). **Физики здесь нет** —
окна только читают ввод, вызывают функции из `calc/` и рисуют результат.

## Как устроено

```
main.py ──► MainWindow
              ├── ParameterPanel   (все параметры, сигнал changed)
              ├── PlotGrid         (7 графиков от λ)
              ├── FilmWindow   ◄── слушает ParameterPanel.changed
              │     └── FitPanel   (подгонка → ParameterPanel.set_model)
              └── AngularWindow ◄── слушает ParameterPanel.changed
```

Параметры вводятся **в одном месте** — в левой панели главного окна.
Окна «Плёнка» и «Под углом» подписаны на её сигнал `changed` и
пересчитываются сами. Поэтому можно держать открытыми два окна рядом:
крутить параметры в главном и смотреть, как меняется совпадение с экспериментом.

## Пересчёт «на лету»

Любое изменение параметра → сигнал `changed` → таймер на 120–150 мс →
`recalculate()`. Таймер нужен, чтобы при зажатой стрелке спинбокса
не пересчитывать на каждый шаг, а только когда пользователь остановился.
2000 точек считаются за миллисекунды, так что задержки не видно.
