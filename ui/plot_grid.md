# plot_grid.py — область графиков

Один виджет на все окна: холст matplotlib + стандартная панель
(домой, назад/вперёд, перемещение, **лупа**, настройка полей, **сохранение картинки**).

## Данные для рисования

```python
Curve(x, y, label, color, experiment=False)   # одна линия
Panel(key, title, x_label, y_label, curves)   # один график (оси)
plot_grid.draw([panel1, panel2, ...])
```

## Раскладка

Число столбцов подбирается по числу отмеченных графиков:

| Графиков | Столбцов | Пример               |
|----------|----------|----------------------|
| 1        | 1        | один на весь экран   |
| 2 – 4    | 2        | 2×2                  |
| 5 – 9    | 3        | 7 графиков → 3×3     |

## Автомасштаб

`autoscale = False` — перед перерисовкой запоминаются пределы осей
каждого графика (по ключу `Panel.key`) и восстанавливаются после.
Так увеличенная лупой область не «слетает» при изменении параметров.
