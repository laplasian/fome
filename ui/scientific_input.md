# scientific_input.py — ввод больших чисел

Концентрации бывают от $0$ до $10^{24}$ см⁻³ — вводить такие числа
в обычное поле неудобно. По условию «лучше, чтобы можно было
редактировать степень отдельно», поэтому поле состоит из двух частей:

$$
N = \underbrace{5.9}_{\text{мантисса}} \times 10^{\overbrace{22}^{\text{степень}}}
$$

| Часть      | Виджет           | Пределы       |
|------------|------------------|---------------|
| мантисса   | `QDoubleSpinBox` | 0 … 9.999     |
| степень    | `QSpinBox`       | 0 … `max_exponent` |

- `value()` — возвращает $\text{мантисса}\cdot10^{\text{степень}}$.
- Сигнал `valueChanged(float)` — при изменении любой из двух частей.

Используется для $N_0$ (до $10^{23}$) и для $N_i$ в таблице мод (до $10^{24}$).
