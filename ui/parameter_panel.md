# parameter_panel.py — панель параметров

Левая часть главного окна. Превращает то, что ввёл пользователь,
в объекты расчётного блока (`calc/parameters.py`).

## Группы

| Группа                   | Поля                                                   |
|--------------------------|--------------------------------------------------------|
| Среда                    | $\varepsilon_\infty$, толщина плёнки $d$ (нм)          |
| Свободные носители       | $N_0$ (мантисса × 10^степень), $m_0/m_e$, $\Gamma_0$   |
| Связанные заряды         | $K$ (1…10) и таблица: $N_i$, $m_i/m_e$, $\lambda_i$, $\Gamma_i$ |
| Диапазон длин волн       | от, до (нм), число точек                               |
| Плазменные частоты       | $\Omega_{p0}, \Omega_{p1}, \dots$ — только показ       |

Пределы и значения по умолчанию — как в условии (см. `calc/parameters.md`).
Исключение: $\varepsilon_\infty \ge 0.001$, так как при нуле $\Omega_p$ не определена.

В таблице мод сразу создаются **все 10 строк**, лишние просто скрываются.
Поэтому если уменьшить $K$, а потом снова увеличить — введённые значения сохранятся.

## Что отдаёт наружу

| Метод / сигнал         | Что это                                       |
|------------------------|-----------------------------------------------|
| `changed`              | сигнал: изменился любой параметр              |
| `material()`           | `Material` — для `calculate_spectrum` и др.   |
| `film_thickness_nm()`  | толщина плёнки, нм                            |
| `wavelength_grid()`    | массив $\lambda$; ошибка, если «от» ≥ «до»    |
| `set_model(material, d)` | записать значения в поля (результат подгонки, «Вернуть как было») |
