# angular_window.py — падение под углом

Длина волны **фиксирована**, по оси X — угол падения $\theta$ от 0 до 90°.
Формулы — в [calc/oblique_reflection.md](../calc/oblique_reflection.md).

## Ввод длины волны

Выпадающий список: **длина волны, нм** или **энергия фотона, эВ**.
При переключении текущее значение пересчитывается ($E = 1240/\lambda$),
так что сама длина волны не меняется. По умолчанию 633 нм (He-Ne лазер).

Рядом показываются $\lambda$, $E$ и $N(\lambda) = n + ik$ среды.

## 5 графиков из условия

| Галочка             | Величина                                        |
|---------------------|-------------------------------------------------|
| R TE (s-волна)      | $R^{TE}_{12}(\theta)$                           |
| R TM (p-волна)      | $R^{TM}_{12}(\theta)$ — минимум у угла Брюстера |
| φ TE, рад           | $\varphi^{TE}_{12}(\theta)$                     |
| φ TM, рад           | $\varphi^{TM}_{12}(\theta)$                     |
| R неполяризованный  | $R^{NP}_{12} = \tfrac12(R^{TE} + R^{TM})$       |

## Сохранение

Имя по умолчанию содержит длину волны: `angular_633nm.txt`.
В шапку файла пишутся $\lambda$, $E$, $N$ и все параметры среды.
