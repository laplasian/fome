# film.py — пропускание и отражение плёнки

Плоскопараллельная плёнка толщиной $d$ в воздухе. Свет падает по нормали.

**Интерференция не учитывается** (сложение по интенсивности, а не по амплитуде —
так и есть для толстой плёнки или немонохроматичного света),
но **многократные переотражения учитываются**.

Используются: $R_{12}(\lambda)$ из `normal_reflection.py`,
$\alpha(\lambda)$ из `refractive_index.py` и толщина
$d\,[\text{см}] = d\,[\text{нм}]/10^7$.

## Формулы

$$
\boxed{\;
T_{film}(\lambda) = \frac{(1 - R_{12})^2\,e^{-\alpha d}}{1 - R_{12}^2\,e^{-2\alpha d}}\cdot 100\%
\;}
$$

$$
\boxed{\;
R_{film}(\lambda) = \frac{R_{12}\left(1 + e^{-2\alpha d} - 2R_{12}\,e^{-2\alpha d}\right)}{1 - R_{12}^2\,e^{-2\alpha d}}\cdot 100\%
\;}
$$

## Откуда берутся (вывод для проверки)

Обозначим $R = R_{12}$, $x = e^{-\alpha d}$ — ослабление за один проход.

Луч, прошедший насквозь: вошёл $(1-R)$, прошёл $x$, вышел $(1-R)$.
Каждое лишнее «туда-обратно» внутри даёт множитель $R^2x^2$:

$$
T = (1-R)^2 x\left(1 + R^2x^2 + R^4x^4 + \dots\right) = \frac{(1-R)^2 x}{1 - R^2x^2}
$$

Отражённый: сразу отразился $R$, плюс лучи, вышедшие назад после
отражения от задней грани:

$$
R_{film} = R + \frac{(1-R)^2 R\,x^2}{1 - R^2x^2}
= \frac{R\,(1 + x^2 - 2Rx^2)}{1 - R^2x^2}
$$

## Проверки

- **Нет поглощения** ($\alpha = 0$, $x = 1$):
  $$T = \frac{1-R}{1+R},\qquad R_{film} = \frac{2R}{1+R},\qquad T + R_{film} = 100\%$$
- **Очень толстая/сильно поглощающая** ($\alpha d \gg 1$): $T \to 0$, $R_{film} \to R_{12}$.
- Для стекла $R_{12} = 0.04$: $T = 92.3\%$, $R_{film} = 7.7\%$.

## Функции

| Функция                                       | Что возвращает      |
|-----------------------------------------------|---------------------|
| `film_transmission(R12, alpha, thickness_nm)` | $T_{film}$, %       |
| `film_reflection(R12, alpha, thickness_nm)`   | $R_{film}$, %       |
| `film_generation_points(R12, alpha, thickness_nm)` | число точек выше порога генерации |

## Замечание

Обе формулы — сумма геометрической прогрессии со знаменателем
$q = R^2 e^{-2\alpha d}$. При $\alpha \ge 0$ всегда $q < 1$.

При отрицательном $\Gamma$ (разрешено условием) $k < 0$ и $\alpha < 0$: свет
внутри плёнки усиливается. Пока $q < 1$, формулы работают, и $T + R > 100\,\%$.
Когда $q \ge 1$ (толстая плёнка, большое $|\alpha|$), ряд расходится — это порог
генерации, конечных $T$ и $R$ нет. В таких точках функции возвращают `NaN`, а
`film_generation_points()` считает их число для предупреждения в окне.

Экспоненты считаются через логарифмы: при $d = 1$ мм и $\alpha \sim -10^4$ см⁻¹
показатель $e^{-\alpha d}$ достигает $e^{1000}$, а предел float — $e^{709}$.
Для $\alpha \ge 0$ результат совпадает с формулами условия до округления
(проверено в `tests/test_edge_cases.py`).
