# comparison.py — сравнение расчёта с экспериментом

Нужно для окна «плёнка»: пользователь подбирает параметры так, чтобы
рассчитанные $T_{film}(\lambda)$ и $R_{film}(\lambda)$ совпали с измеренными.

## Проблема

Расчёт сделан на своей сетке $\lambda$ (например, 2000 точек от 190 до 2500 нм),
а прибор выдаёт точки на своей. Чтобы сравнивать, нужна **одна сетка**.

## Решение

1. Берём точки эксперимента $\lambda_j$, попадающие в диапазон расчёта.
2. Линейно интерполируем расчёт в эти точки: $y^{calc}(\lambda_j)$.
3. Считаем среднеквадратичное отклонение:

$$
\boxed{\;
\text{RMS} = \sqrt{\frac{1}{M}\sum_{j=1}^{M}\left(y^{calc}(\lambda_j) - y^{exp}_j\right)^2}
\;}
\qquad [\%]
$$

Чем меньше RMS — тем лучше совпадение. Это одно число, которое удобно
показывать в интерфейсе рядом с графиком, а в будущем — минимизировать
при машинной подгонке параметров.

## Функции

| Функция                                                 | Что делает                     |
|---------------------------------------------------------|--------------------------------|
| `interpolate_onto(x_calc, y_calc, x_new)`               | интерполяция на новые точки    |
| `compare_with_experiment(λ_calc, y_calc, λ_exp, y_exp)` | → `Comparison` (общая сетка + RMS) |

## Пример

```python
from calc.data_io import load_experimental_spectrum
from calc.comparison import compare_with_experiment

wl_exp, T_exp = load_experimental_spectrum("T_sample.txt")
c = compare_with_experiment(spectrum.wavelength_nm, spectrum.film_T_percent, wl_exp, T_exp)
print(f"RMS = {c.rms:.2f} %")
```

## Задел на машинную подгонку (опция для команды из 3 человек)

Подгонка — это поиск параметров, минимизирующих
$\text{RMS}_T^2 + \text{RMS}_R^2$, при условии, что каждый параметр
либо закреплён, либо меняется в пределах «от — до», заданных пользователем.
Функция `compare_with_experiment` уже даёт всё нужное для целевой функции.
