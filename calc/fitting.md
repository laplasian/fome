# fitting.py — машинная подгонка параметров

Задача: найти параметры модели, при которых рассчитанные $T_{film}(\lambda)$ и
$R_{film}(\lambda)$ лучше всего совпадают с измеренными.

## Что минимизируется

$$
\boxed{\;
F(\mathbf{p}) = \text{RMS}_T^2 + \text{RMS}_R^2
\;}
$$

$$
\text{RMS}_T^2 = \frac{1}{M_T}\sum_{j=1}^{M_T}\left(T^{calc}(\lambda_j;\mathbf{p}) - T^{exp}_j\right)^2,
\qquad
\text{RMS}_R^2 = \frac{1}{M_R}\sum_{j=1}^{M_R}\left(R^{calc}(\lambda_j;\mathbf{p}) - R^{exp}_j\right)^2
$$

- $\mathbf{p}$ — параметры, отмеченные «подгонять». Остальные **закреплены**.
- Каждый подгоняемый параметр ограничен: $p_{min} \le p \le p_{max}$ (пределы «от – до»).
- Если загружен только один спектр (например, только $T$), второе слагаемое отсутствует.
- Расчёт ведётся **прямо в точках эксперимента** $\lambda_j$ — без интерполяции.

Деление на $M$ уравнивает вклад $T$ и $R$, даже если в файлах разное число точек.

### Как это записано для оптимизатора

Функция `residuals` возвращает вектор невязок

$$
r = \left(\frac{T^{calc}_1 - T^{exp}_1}{\sqrt{M_T}},\ \dots,\ \frac{R^{calc}_1 - R^{exp}_1}{\sqrt{M_R}},\ \dots\right),
\qquad
\sum r_j^2 = F(\mathbf{p})
$$

Именно такой вид нужен методу наименьших квадратов.

## Единичный куб и логарифм для концентраций

Параметры отличаются на десятки порядков ($N \sim 10^{21}$, $\varepsilon_\infty \sim 1$),
поэтому оптимизатор работает не с ними, а с безразмерными $u \in [0, 1]$:

$$
p = p_{min} + u\,(p_{max} - p_{min})
\qquad\text{или для концентраций}\qquad
\log_{10} N = \log_{10} N_{min} + u\,(\log_{10} N_{max} - \log_{10} N_{min})
$$

$u = 0$ — предел «от», $u = 1$ — предел «до». Так все параметры «равноправны»,
а пределы соблюдаются автоматически.

Концентрации ищутся в логарифме, потому что важен порядок величины:
шаг от $10^{20}$ до $2\cdot10^{20}$ так же значим, как от $10^{21}$ до $2\cdot10^{21}$.
(Если нижний предел концентрации равен 0, логарифм невозможен — тогда линейно.)

## Два метода

| Метод        | Как работает                                                    | Когда брать |
|--------------|-----------------------------------------------------------------|-------------|
| `"local"`    | Наименьшие квадраты с границами (`scipy.optimize.least_squares`, метод *trf*) от **текущих** значений | Начальные значения уже близки (подобраны руками). Секунды. |
| `"global"`   | Дифференциальная эволюция (`scipy.optimize.differential_evolution`) по **всей** области «от – до», затем уточнение локальным методом | Не знаете, где минимум; много параметров; локальный застрял. Дольше. |

**Локальный метод** спускается в ближайший минимум. У резонансов Лоренца бывает
много локальных минимумов (пик «зацепился» не за ту особенность), поэтому, если
результат плохой, — сузьте пределы вручную или включите глобальный.

**Дифференциальная эволюция**: популяция из $15 \times n$ случайных точек в области
(n — число параметров) «скрещивается» и отбирается по $F$; до 150 поколений.
Начальная точка (текущие значения) включена в популяцию.

## Остановка

`should_stop()` проверяется перед каждым расчётом. Если вернула `True` —
подгонка прерывается, и возвращается **лучшая точка, найденная к этому моменту**
(`stopped = True`).

## Функции

| Функция                                         | Что делает |
|-------------------------------------------------|------------|
| `list_parameters(material, d)`                  | все параметры модели с пределами по умолчанию |
| `default_bounds(key, value)`                    | пределы «от – до» вокруг текущего значения |
| `get_value / with_values`                       | чтение/замена параметра по ключу (`"bound.0.wavelength_nm"`) |
| `residuals(material, d, experiments)`           | вектор невязок $r$ |
| `rms_by_experiment(material, d, experiments)`   | `{"T": RMS_T, "R": RMS_R}` |
| `fit_parameters(material, d, parameters, experiments, method, on_progress, should_stop)` | подгонка → `FitResult` |

`FitResult`: подогнанные `material` и `film_thickness_nm`, словарь найденных
значений `values`, `rms` до и после, число вычислений спектра, флаг `stopped`.

### Пределы по умолчанию (`default_bounds`)

| Параметр       | от                    | до                  |
|----------------|-----------------------|---------------------|
| $N$            | $N/10$ (или $10^{15}$)| $10N$ (или $10^{22}$) |
| $m/m_e$        | $m/3$                 | $3m$                |
| $\lambda_i$    | $0.8\lambda_i$ (≥ 100)| $1.2\lambda_i$ (≤ 10 000) |
| $\Gamma$       | $\Gamma/10$ (≥ 1)     | $10\Gamma$          |
| $\varepsilon_\infty$ | $\varepsilon_\infty/2$ | $2\varepsilon_\infty$ |
| $d$            | $0.5d$                | $1.5d$              |

Это только стартовые подсказки — **физически разумные пределы выбирает пользователь**.

## Пример

```python
from calc.fitting import list_parameters, fit_parameters

params = list_parameters(material, d)
for p in params:
    if p.key in ("bound.0.wavelength_nm", "film_thickness_nm"):
        p.fit = True                     # остальные закреплены

experiments = {"T": (wl_T, T_exp), "R": (wl_R, R_exp)}
result = fit_parameters(material, d, params, experiments, method="local")
print(result.values, result.rms)
```
