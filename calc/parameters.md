# parameters.py — входные параметры

Здесь описано **что задаёт пользователь**. Расчётов в этом файле нет.

## Среда (`Material`)

| Поле           | Обозначение            | По умолчанию | Пределы   |
|----------------|------------------------|--------------|-----------|
| `eps_inf`      | $\varepsilon_\infty$   | 1            | 0 … 1000  |
| `free`         | свободные носители     | см. ниже     |           |
| `bound_modes`  | список мод, $K$ штук   | 1 мода       | 1 … 10    |

## Свободные носители (`FreeCarriers`) — вклад Друде

| Поле                | Обозначение | Единицы            | По умолчанию | Пределы             |
|---------------------|-------------|--------------------|--------------|---------------------|
| `concentration_cm3` | $N_0$       | см⁻³               | 0            | 0 … $10^{23}$       |
| `mass_in_me`        | $m_0/m_e$   | массы электрона    | 1            | > 0                 |
| `damping_cm1`       | $\Gamma_0$  | см⁻¹               | 100          | ±$10^5$ (можно < 0) |

$N_0 = 0$ означает диэлектрик (нет свободных электронов).

## Мода связанных зарядов (`BoundMode`) — осциллятор Лоренца

| Поле                | Обозначение   | Единицы         | По умолчанию | Пределы             |
|---------------------|---------------|-----------------|--------------|---------------------|
| `concentration_cm3` | $N_i$         | см⁻³            | 0            | 0 … $10^{24}$       |
| `mass_in_me`        | $m_i/m_e$     | массы электрона | 1            | > 0                 |
| `wavelength_nm`     | $\lambda_i$   | нм              | 200          | 100 … 10 000        |
| `damping_cm1`       | $\Gamma_i$    | см⁻¹            | 1000         | ±$10^5$ (можно < 0) |

Резонансная частота считается из длины волны:
$\nu_i = 10^{7} / \lambda_i$ (по умолчанию 200 нм → 50 000 см⁻¹).

## Прочее

| Константа                      | Значение            |
|--------------------------------|---------------------|
| `DEFAULT_FILM_THICKNESS_NM`    | $10^6$ нм = 1 мм (пределы 1 … $10^7$ нм) |
| `DEFAULT_WAVELENGTH_RANGE_NM`  | 190 … 2500 нм       |
| `MAX_BOUND_MODES`              | 10                  |

Словарь `LIMITS` хранит все пределы, чтобы интерфейс мог проверять ввод.

`describe_material(material)` возвращает параметры текстом — они пишутся
в заголовок каждого сохранённого файла, чтобы было видно, при каких
параметрах получен результат.

## Пример

```python
from calc.parameters import Material, FreeCarriers, BoundMode

gold_like = Material(
    eps_inf=9.0,
    free=FreeCarriers(concentration_cm3=5.9e22, mass_in_me=1.0, damping_cm1=100),
    bound_modes=[BoundMode(concentration_cm3=1e22, wavelength_nm=400, damping_cm1=5000)],
)
```
