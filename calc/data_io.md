# data_io.py — импорт эксперимента и экспорт результатов

## Импорт экспериментального спектра

Файл — **2 столбца** в текстовом виде:

```
# любые строки заголовка пропускаются
190.0    12.31
191.0    12.48
...
```

1-й столбец — длина волны в **нм**, 2-й — пропускание или отражение в **%**.
Пропускание и отражение — **два разных файла**.

Как читается строка (`parse_two_numbers`):

| Пример строки        | Разделитель      | Результат        |
|----------------------|------------------|------------------|
| `190.5	45.3`         | табуляция        | 190.5, 45.3      |
| `190.5   45.3`       | пробелы          | 190.5, 45.3      |
| `190,5;45,3`         | `;` (запятая — десятичная) | 190.5, 45.3 |
| `190,5	45,3`         | табуляция (запятая — десятичная) | 190.5, 45.3 |
| `190.5,45.3`         | запятая (CSV)    | 190.5, 45.3      |
| `190.5, 45.3`        | запятая + пробел | 190.5, 45.3      |
| `190,45`             | запятая (CSV)    | 190, 45          |
| `Wavelength  %T`     | —                | пропущена        |

Правило: если в строке есть точка **или** нет других разделителей
(пробел, табуляция, `;`) — запятая считается разделителем столбцов,
иначе — десятичным знаком.

После чтения точки сортируются по возрастанию длины волны.
Реальные файлы приборов могут иметь другой формат — тогда правится только
`parse_two_numbers`.

## Экспорт

Формат — текст (только ASCII), столбцы через табуляцию, шапка с `#`:

```
# Drude-Lorentz model, normal incidence from air
# eps_inf = 1
# N0 = 1e+22 cm^-3, m0 = 1 m_e, Gamma0 = 100 cm^-1
# K = 1
# mode 1: N = 0 cm^-3, m = 1 m_e, lambda = 200 nm, Gamma = 1000 cm^-1
# film thickness d = 1e+06 nm
# wavelength_nm	n	k
190	0.0123	1.234
...
```

Параметры, при которых получен результат, всегда записаны в шапке —
файл можно открыть через месяц и понять, откуда он.
Такой файл открывается в Excel, Origin, или обратно в numpy (`np.loadtxt`).

| Функция                                          | Что делает                          |
|--------------------------------------------------|-------------------------------------|
| `load_experimental_spectrum(path)`               | → `(wavelength_nm, values_percent)` |
| `save_table(path, columns, header_lines)`        | общая запись столбцов               |
| `save_spectrum(path, spectrum, keys, material, x_axis)` | выбранные графики от λ (или от E при `x_axis="ev"`) |
| `save_angular_spectrum(path, angular, keys, material)`  | выбранные графики от угла; λ и E в шапке |
| `angular_file_name("gold", 633)`                 | → `"gold_633nm.txt"` — λ в имени файла |

Ключи для `keys` — из `SPECTRUM_QUANTITIES` (spectrum.py) и
`ANGULAR_QUANTITIES` (angular_spectrum.py).
